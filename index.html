TechStack

  • ReactJS

    ReactJS is a JavaScript library used for building user interfaces, particularly for single-page applications where you need a fast, interactive experience.

  • React Native

    React Native is an open-source framework for building mobile applications using JavaScript and React. It allows developers to create apps for iOS and Android using a single codebase, while providing native performance and look-and-feel. React Native leverages native components and APIs, meaning that it renders mobile interfaces using platform-specific components, offering users a seamless experience.

  • ExpressJS

    Express.js is a lightweight and flexible web application framework for Node.js. It simplifies the process of building web servers and APIs by providing a set of tools for routing, middleware, and request handling.

  • NodeJS

    Node.js is a JavaScript runtime built on Chrome's V8 engine that allows developers to run JavaScript on the server side.

  • TypeScript

    TypeScript adds static types to JavaScript. I use it for React, Next.js, and Vite projects such as S.A.F.E.R., LinkCraft, and the Science Quiz Game, where typed API clients and stores catch mistakes before they ship.

  • Next.js

    Next.js is a React framework with file-based routing, server rendering, and API routes. I used the App Router with Supabase, TanStack Query, and Zustand to build the LinkCraft URL shortener.

  • Laravel

    Laravel is a PHP framework for building APIs and web applications. I build Laravel 12 REST APIs with Sanctum authentication, role and permission middleware, queued jobs, and MySQL, as in S.A.F.E.R., the Science Quiz Game, and POS Warehouse.

  • Grafana

    Grafana visualizes metrics, logs, and traces. I maintain metrics and logs explorer dashboards as JSON in git for dozens of production services, covering RED metrics, business telemetry, JVM and HikariCP pools, Kafka, SLOs, and trace drill-downs into Tempo.

  • OpenTelemetry

    OpenTelemetry is the open standard for traces, metrics, and logs. I wire OTLP exporters into Spring Boot and Node.js services, add HTTP, JDBC, and Kafka spans, and propagate trace IDs into structured logs so a request can be followed end to end.

  • Prometheus

    Prometheus collects time-series metrics. I expose Micrometer and prom-client endpoints, configure Grafana Alloy scrape targets, and write PromQL for rates, error ratios, latency percentiles, and SLO burn rates.

  • Java Spring Boot

    Spring Boot is a Java framework for production microservices. I instrument Spring Boot services with Actuator, Micrometer, Log4j2 structured logging, and JDBC tracing, and fix issues such as connection-pool sizing and scrape endpoints.

  • TailwindCSS

    Tailwind CSS is a utility-first CSS framework that allows developers to style their applications directly in the HTML using pre-defined classes. Instead of writing custom CSS, you apply classes for margins, padding, colors, typography, and more, making the design process faster and more consistent. It provides a responsive and mobile-first design approach out of the box and supports customization through configuration files. Tailwind CSS is widely appreciated for its simplicity, flexibility, and ability to create modern, clean designs without leaving the HTML structure.

  • Webpack

    Webpack is a powerful module bundler for JavaScript applications. It takes all the assets in your project—JavaScript, CSS, images, and more—and bundles them into optimized files for the browser. Webpack also supports advanced features like code splitting, lazy loading, and tree-shaking to improve application performance. It allows developers to define custom configurations, manage dependencies efficiently, and transform modern JavaScript or CSS (via loaders) into a format supported by all browsers. Webpack is widely used in modern web development for its flexibility and ability to streamline the build process.

  • Git

    Git is a distributed version control system that helps developers track changes in their codebase, collaborate with others, and manage different versions of their projects. It allows you to create snapshots of your work (commits), roll back to previous states, and work on new features or fixes in isolated branches. Git is known for its speed, reliability, and support for distributed workflows, enabling teams to work asynchronously. It is widely used in software development to maintain code history, resolve conflicts, and collaborate effectively, with platforms like GitHub or GitLab often used for hosting repositories.

  • Github

    GitHub is a web-based platform for version control and collaboration that uses Git. It allows developers to host their code repositories, share projects, and collaborate with others. GitHub provides tools for managing code changes, tracking issues, and reviewing pull requests, making it easier for teams to work together. It also offers features like GitHub Actions for automation, GitHub Pages for hosting static websites, and a vast ecosystem of open-source projects. GitHub is widely used for both individual and team-based development, fostering collaboration and community engagement.

  • NPM

    npm (Node Package Manager) is a tool that comes bundled with Node.js and is used for managing packages (libraries, frameworks, or tools) in JavaScript projects. npm simplifies development by providing access to a massive ecosystem of reusable code, speeding up the process of building and maintaining applications.

  • MySQL

    MySQL is an open-source relational database management system (RDBMS) that uses Structured Query Language (SQL) to manage and manipulate data. It is widely used for storing and retrieving data in web applications and other software systems.
